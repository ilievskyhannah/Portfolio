# Portfolio

Hannah Ilievsky's product design portfolio. Static HTML/CSS site, no build step.

## Structure

- `index.html` — homepage (hero, selected work, about, contact)
- `case-studies/facts-commando.html` — Facts Commando case study
- `assets/css/style.css` — shared stylesheet
- `assets/images/` — site images

## Running locally

```
npx serve
```

Then open the URL it prints (defaults to `http://localhost:3000`).
